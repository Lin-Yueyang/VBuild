# 方向轴与网格

方向轴能拖动定位，刻度轴、网格和平面按结构独立显示，默认沿晶胞 a/b/c；这些辅助图形不修改坐标、晶胞或周期性。

## 方向轴

左下角的 +X/+Y/+Z 方向轴在播放轴上方定位，不随播放窗口遮住一部分。鼠标移到方向轴区域变为手形，按住左键拖动，可移到可见视窗的四周附近。位置按可见视窗比例保存；下次启动、调整窗口和播放轴高度时仍在对应位置。方向轴拖动不旋转结构，普通区域的旋转和平移沿用原操作。

“设置→原子与键→显示 xyz 方向轴”默认勾选，可单独隐藏这个方向标记，重启保留；不影响下面单独配置的真实刻度轴/网格。

## 轴 / 网格

点击左侧“显示晶胞参数”下方的“显示轴/网格”，打开可移动、可调整宽高的面板。参数即时生效，仍可旋转、平移、选择原子和播放；关闭面板右上角 × 仅收起设置，取消“显示”则关闭辅助图形。

- 默认“沿晶胞 a/b/c”，三条轴沿原晶胞矢量绘制，夹角可以不是 90°，从共同零点出发；公共 0 只在第一条可见轴上显示。刻度是沿相应矢量的 Å 距离，不是分数坐标。
- a/b/c 三行分别控制轴、网格和平面。固定 c 的平面平行 a/b，位置值是沿 c 的距离；斜晶胞下这个距离和面法向距离可以不同。
- 可切换“笛卡尔 x/y/z”，保留绝对笛卡尔范围。例如 Z 平面平行 XY，位置值为 z 坐标。无晶胞结构只启用此模式，并按当前原子范围布置；不改变后续有晶胞结构的基准偏好。
- 默认同时显示三个轴，间隔 3 Å、小数位 0，只标范围内的 0、3、6、9 等倍数；笛卡尔负范围也支持 −3、−6。网格和平面默认关闭。轴名放在最大刻度一端，沿晶胞标为 a/b/c，笛卡尔标为 X/Y/Z。
- 基础面板依次提供基准、显示选择、a/b/c（或 xyz）平面位置、刻度间隔和小数位。点击“高级参数”展开字号、线宽、轴距晶胞和各类不透明度，默认折叠。面板内容靠顶部紧凑排列，不因旧的大窗口尺寸把各行拉开。每方向最多 1000 个刻度，过密时提示增大间隔。
- 沿晶胞模式中，轴距晶胞为 0 时，标尺零点在晶胞原点；正偏移将整套标尺平移到晶胞外，刻度仍表示相对于标尺零点的距离。网格和平面保持按实际晶胞定位。
- 平面默认位于对应坐标的下边界；启用该方向的网格或平面后，可在基础面板直接输入位置。高级参数中的“平面位置恢复贴边”恢复自动位置。

各结构页保留独立开关和参数；分页对比引用同一结构设置。最近的参数作为后续新页默认参数，但新页仍默认关闭辅助图形。周期镜像显示范围变化时，刻度范围随之更新；轨迹变晶胞时重新更新。辅助图形不参与原子拾取或结构导出，渲染图片的“辅助信息”关闭时一并隐藏。

## 周期性边界

“设置→原子与键→显示周期性边界”默认勾选。取消后隐藏晶胞边框，当前窗口和分页同步生效，重启保留；原晶胞、周期性、扩胞、计算和导出仍使用原数据。渲染样式里单独关闭晶胞显示的设置也继续有效。

## 状态栏

状态栏按结构中的元素顺序显示总数量，例如 `C 64 O 1 | 65 原子 | 已选 0`，不把显示的周期镜像重复计数。无结构温度时不再写“无导出速度”，有温度时仍显示温度。
