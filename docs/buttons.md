# 按钮与功能

鼠标右键拖动平移，滚轮缩放；默认快捷键可在“设置 → 快捷键”修改。

## 顶部工具栏

| 按钮 | 用途 |
|---|---|
| 撤销 / 重做 | 返回前后操作；下拉列表可一次返回多步。 |
| a / b / c | 沿对应晶胞方向观察，再按一次切换正反方向。 |
| 六个旋转箭头 | 按当前视角上下、左右或侧转；选中至少三个原子时旋转原子组。 |
| 切面扩胞 | 按 Miller 指数切面、重复晶胞并增加真空；勾选“仅扩胞”可跳过切面。 |
| 添加原子 | 从周期表选择一个元素，随后用鼠标放置；Esc 取消。 |
| 添加分子 | 放置常见分子，通过 SMILES 构建分子，或添加水层、指定数量的水分子。 |
| 改胞 | 寻找最小原胞、调整晶胞边界或匹配参考结构的边长，预览后新建结构页。 |
| 剪贴板 | 查看近期复制的原子组，在不同结构页之间粘贴。 |
| 归入晶胞 | 将周期外的原子或相连分子移回晶胞，保持周期结构。 |
| 分页窗口 | 用两列、三列或四格对比结构；拖入标签或文件，每格可独立操作，并可同步视角。 |
| 双行目录标签 | 标签同时显示上一级目录与文件名。 |
| 外观调色盘 | 选择清晰、塑料、橡胶、卡通等外观，并控制是否显示键。 |

## 左侧工具栏

| 按钮 | 用途 |
|---|---|
| 旋转（R） | 左键拖动旋转视角。 |
| 选择（S） | 单击或框选原子，Ctrl 多选，Shift+单击选择相连分子。 |
| 距离（D） | 依次选两个原子，测量距离。 |
| 角度（A） | 依次选三个原子，测量以第二个原子为顶点的角度。 |
| 二面角 | 依次选四个原子，测量二面角。 |
| 面夹角 | 依次选择两组三个原子，测量两个平面的夹角。 |
| 编辑（E） | 拖动原子组、方向键微调，或在原子信息框中修改元素和坐标。 |
| 模型风格 | 切换球棍、空间填充、多面体、棍状模型；空格也可切换。 |
| 检测原子过近 | 高亮距离过近的原子，并显示距离。 |
| 显示固定原子 | 标记被固定的原子。 |
| 显示晶胞参数 | 在视窗中显示晶胞长度和夹角。 |
| 显示轴/网格 | 显示沿晶胞或笛卡尔方向的标尺、网格和平面，调整刻度和位置。 |
| 显示周期性 | 调整 a/b/c 三个方向的周期镜像数量。 |
| 显示原子序号 | 显示元素与全局序号，可按元素筛选。 |
| 显示播放轴 | 显示或隐藏轨迹播放控件。 |
| 文件能量与力 | 查看导入计算文件中包含的能量、受力等数据。 |
| CHGCAR | 显示电荷等值面；差分电荷可分别调整正负等值和颜色。 |
| Bader 电荷 | 从结构所在目录读取 Bader 数据，显示电荷或原始表格，并按元素筛选。 |
| 磁矩 | 从 OUTCAR 读取磁矩，选择总值或轨道分量、筛选元素并查看原始数据。 |
| ELFCAR | 显示 ELF 等值面或切片，二维切片支持导出图片。 |
| NEB | 扫描并导入 NEB 目录，叠加各图像，查看数据、优化曲线和能量路径。 |
| 显示原子受力 | 用所选 MLIP 计算受力，以箭头标记超过阈值的原子。 |
| MLIP 结构优化 | 新建优化页，默认临时固定全部原子；解除目标原子的固定后开始优化。 |
| MLIP 预平衡 | 新建分子动力学预平衡页，设置温度、步数、步长及可选上下墙。 |
| 渲染 | 调整元素、原子、键和光照外观，导入或保存样式、保存完整场景。 |

右键左侧按钮可隐藏；右键空白可恢复显示。按住按钮可在同一分隔区域内调整顺序。测量标记会随轨迹刷新，双击空白清除。

## 新建、编辑与分子构建

“文件”中可新建空晶胞，或从 Materials Project、石墨烯、碳纳米管构建结构；打开、关闭和导出位于同一菜单。“导出结构”保存当前帧，“导出轨迹”保存完整或按间隔抽取的轨迹。

| 按钮 | 用途 |
|---|---|
| 预览 | 根据当前参数生成预览；切面、改胞和结构构建确认前需先预览。 |
| 搜索 | 按输入的化学式或元素搜索 Materials Project。 |
| 应用 / 构建 / 确定 | 确认当前参数或所选结果。 |
| 复制到剪贴板 | 保存已预览的 SMILES 分子，随后按 Ctrl+V 放置；回车仅重新预览。 |
| 安装 RDKit | 缺少 SMILES 依赖时确认安装，完成后继续预览。 |
| 固定所选原子（F） | 分别设置 x/y/z 固定状态；Ctrl+F 快速切换全部固定或解除固定。 |
| 原子信息框中的应用 | 保存编辑后的坐标；元素修改立即生效，选择模式仅显示信息。 |

复制、粘贴、删除分别用 Ctrl+C、Ctrl+V、Del；粘贴预览中可用上下方向键切换剪贴板记录，Esc 取消。

## 优化、预平衡与轨迹

| 按钮 | 用途 |
|---|---|
| 选择 / 加载模型 | 选择模型文件，提前加载到所选 CPU 或 GPU。 |
| 开始优化 / 开始预平衡 | 从准备好的结构开始计算。 |
| 停止 | 结束当前计算，保留已经完成的帧。 |
| 预览墙位置 | 显示上下软墙的位置。 |
| 显示过程 | 开关能量、最大受力和速度等过程信息。 |
| 查看数据 / 查看曲线 | 打开右侧数据表或曲线；双击数据行或曲线可跳帧并暂停。 |
| 导出轨迹 / 最终结构 / 数据 | 分别保存 XDATCAR、最终结构和逐步 CSV 数据。 |
| 曲线勾选项 | 选择显示温度、原子最大受力、势能中的哪些曲线。 |
| 能量单位 / 相对首帧 | 切换势能显示单位，或查看相对首个有效能量帧的变化。 |
| 最小 / 最大 / 自动 / 全部 | 设置坐标范围，恢复自动纵轴或显示全部横轴数据。 |
| 导出曲线图片 | 按当前显示的曲线和坐标范围保存 PNG。 |
| 播放 / 上一帧 / 下一帧 | 控制轨迹；也可拖进度条、输入帧号或调整帧/秒。 |

曲线中左键拖动平移横轴，右键框选横向范围；滚轮缩放纵轴，Shift+滚轮缩放横轴。

## NEB 与渲染

| 按钮 | 用途 |
|---|---|
| NEB 扫描 / 刷新 / 导入 | 检查目录中的图像结构，刷新文件列表，确认后读取轨迹和能量。 |
| 全部显示 / 全部隐藏 | 切换 NEB 图像叠加，独立于数据与曲线筛选。 |
| 图像勾选 / 不透明 | 选择叠加的结构，以及哪些结构保持不透明。 |
| 00、01 等图像按钮 | 选择数据和曲线中显示哪些图像。 |
| 能量路径 / 优化曲线 | 分别查看当前播放帧的路径能量和各图像的优化过程。 |
| 选择、保存与分享样式 | 展开通用样式及完整场景的管理区。 |
| 保存样式 / 导入 / 导出 | 保存或分享可跨结构复用的外观。 |
| 保存 / 打开渲染场景 | 保存或恢复当前结构、单原子外观、视角及显示设置。 |
| 周期表 / 选取原子 | 调整指定元素，或只调整某一个原子的外观。 |
| 将此材质应用到所有元素 | 统一各元素的材质参数。 |
| 恢复元素 / 原子外观 | 恢复 Default 元素外观，或让单原子重新沿用元素设置。 |
| 按元素对设置键长范围 | 调整各元素对自动成键的距离范围。 |
| 导出 PNG 图片 | 保存当前渲染视图。 |

## 设置与数据窗口

“设置”按编辑与视角、原子与键、电子数据、文字、快捷键、Python 与 MLIP 分类。文字大小、描边、键半径、测量小数位和显示开关等在对应页面调整。

| 按钮 | 用途 |
|---|---|
| 检测并使用 | 检查选择的 Python，保存路径，重启后使用。 |
| 安装建模依赖 | 为所选 Python 安装界面和建模所需的库。 |
| 下载 | 为勾选的 MLIP 下载模型及相应计算库；GPU 选项准备计算后端。 |
| 模型目录图标 | 打开模型文件所在目录。 |
| 显示详情 | 展开可复制的检测、安装或错误信息。 |
| 继续安装 / 重试 | 确认已有依赖的变更，或重新检查并安装。 |
| 取消下载 / 取消安装 | 停止当前下载或安装过程。 |
| 查看原始数据 / 重新读取 | 展示文件中的数据表，或重新读取当前来源文件。 |
| 启用 / 关闭显示 | 切换对应的受力、电荷、磁矩或电子数据标记。 |
| 恢复默认 | 恢复对应设置页的默认值。 |
| × / 取消 | 关闭小窗或退出当前操作。 |
