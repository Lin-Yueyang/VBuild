# 版本记录

## 1.0.0 2026-11-25

- a、b、c 按钮沿最短路径对齐晶轴，修复负轴视角的镜像。设置可开启右下角的整数缩放比例，点击数字即可精确调整。
- 建模视图新增 VESTA 配色、“粉彩柔光”和自定义样式管理，支持用虚线显示氢键。含分子动力学续算数据的 POSCAR 可在新标签页中编辑副本。
- PNG 导出默认使用 4 倍分辨率，晶胞边界沿用当前视图，保存时显示进度提示。修复从 XDATCAR 导出的单帧结构再次打开时报错。
- 可在启动后后台加载选定的本地 MLIP 模型，按需清理缓存。Windows 从外部打开的文件会加入已有窗口，固定到任务栏后可使用 VBuild 图标启动。

## 0.3 系列（截至 0.3.46） 2026-11-20

- Windows 轻量版支持选择本机 Python、安装建模依赖和检查更新。
- 结构与轨迹可分屏对比，支持 MLIP 优化与预平衡、NEB 路径分析、电荷与磁矩显示。
- 文件菜单支持导出当前结构、轨迹和图片，导出窗口可直接输入目录。
