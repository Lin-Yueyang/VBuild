# 版本记录

## 0.3.44-0.3.46 2026-11-20

- 下载更新后可选择稍后重启。关闭更新窗口可继续工作，正常退出时安装，下次启动使用新版。
- 磁矩最多显示三位小数。播放和前后逐帧按钮的宽高增加 50%，悬停时显示手形指针。
- 首次启动使用单行标签，左侧默认收起九个工具，球棍等模型选择移到顶部。建模依赖安装失败会保留 pip 输出，可复制日志路径。
- 新增当前视图图片导出，支持透明背景、晶胞边界和自选底色。设置中可按元素修改建模配色和调整键粗细。
- 导入 CHGCAR、ELFCAR 和含逐原子磁矩的 OUTCAR 时自动显示对应数据。电荷正负等值面默认取 +0.01 和 −0.01。
- 导入上述文件时也会打开对应的设置面板，可直接调整等值面、切片或磁矩显示。

## 0.3.42-0.3.43 2026-11-09

- 导出窗口可在顶部粘贴目录并回车跳转。采用 Win11 风格导航箭头，文件区空白处右键可切换视图和新建文件夹。
- 静态 CONTCAR 的全零速度无需重新赋温。若有保存问题，在导出窗口内修改后即可重试。

## 0.3.40-0.3.41 2026-11-03

- 导出窗口可直接输入或粘贴目录地址，回车定位，也可直接保存到输入的目录。
- a/b 视角优先保持 Z 向上；六个旋转按钮按方向成对分组，重画箭头并增加文字。
- LAMMPS dump 的末帧未写完时保留前面的完整轨迹，并显示提示，避免索引失败后只显示 1 帧。

## 0.3.39 2026-11-02

- 大轨迹后台导出，显示帧数进度并支持取消，取消或失败时保留原文件。
- 优化和预平衡支持暂停、继续及完成后延长目标总步数，保留已有轨迹；增加预计剩余时间。
- 开始按钮更明显，上下墙设置及预览默认折叠在高级参数中。
- 移除独立更新说明文件及主页的对应链接。

## 0.3.30-0.3.38 2026-11-01

- 新增 DPA4C OMol25 Neo，受力、优化和预平衡共用；安装前确认已有依赖的版本变更，改善计算面板在不同屏幕上的布局。
- 新增可拖动的方向轴，以及沿真实晶胞的标尺、网格和平面；可隐藏晶胞边界和方向轴，调整平面位置，收紧面板排版。
- 曲线支持切换能量单位和显示相对首帧能量，坐标范围、悬停与图片同步换算。导出增加桌面入口，改名后的 XDATCAR 也能按内容识别。
- SMILES 回车只预览，缺少 RDKit 时可确认后一键安装。精简主页，新增按钮说明和版本记录，分享文件不再附带样例。
- 设置增加 GitHub 检查更新，显示当前和最新版本，支持下载、备份旧程序后安装并重启；直接读取公开仓库，无需登录或设置令牌。

## 0.3.27-0.3.29 2026-10-30

新增晶胞参数显示和“改胞”，支持最小原胞、边界形状搜索及双结构共同扩胞匹配。改胞窗口加入双方独立预览、可调分隔条和“扩胞前单元”输出，应用后新建结构页；标签拖动增加位置预览和动画。

## 0.3.25-0.3.26 2026-10-28
