# 版本记录

## 0.3.30-0.3.38 2026-11-01

- 新增 DPA4C OMol25 Neo，受力、优化和预平衡共用；安装前确认已有依赖的版本变更，改善计算面板在不同屏幕上的布局。
- 新增可拖动的方向轴，以及沿真实晶胞的标尺、网格和平面；可隐藏晶胞边界和方向轴，调整平面位置，收紧面板排版。
- 曲线支持切换能量单位和显示相对首帧能量，坐标范围、悬停与图片同步换算。导出增加桌面入口，改名后的 XDATCAR 也能按内容识别。
- SMILES 回车只预览，缺少 RDKit 时可确认后一键安装。精简主页，新增按钮说明和版本记录，分享文件不再附带样例。
- 设置增加 GitHub 检查更新，显示当前和最新版本，支持下载、备份旧程序后安装并重启；直接读取公开仓库，无需登录或设置令牌。

## 0.3.27-0.3.29 2026-10-30

新增晶胞参数显示和“改胞”，支持最小原胞、边界形状搜索及双结构共同扩胞匹配。改胞窗口加入双方独立预览、可调分隔条和“扩胞前单元”输出，应用后新建结构页；标签拖动增加位置预览和动画。

## 0.3.25-0.3.26 2026-10-28

切面、扩胞预览和应用保留当前视角，结果显示各元素数量、晶胞向量及角度。默认切面改为 (111)，核对常规晶胞基准、Bi 和 Bi₂CO₅ 的切面结果。

## 0.3.0.dev23-0.3.24 2026-10-26

设置新增快捷键和文字外观调整，字体、描边支持预览与恢复默认。简化磁矩汇总排版，修复 Mac 测试版的启动资源路径，并开始使用三段数字版本号。

## 0.3.0.dev18-0.3.0.dev22 2026-10-24

新增塑料、橡胶、卡通、2D 等外观风格，以及独立的显示键开关；改进元素编辑、键长范围、按钮显隐和组内排序。优化 Materials Project 搜索和分子选择，验证轻量部署，并开展 Mac 轻量版适配测试。

## 0.3.0.dev15-0.3.0.dev17 2026-10-23

磁矩汇总改为已显示原子合计、全部原子合计、体系自旋总磁矩三行，数字和单位对齐。保存窗口位置与大小，减少重复启动窗口和首屏加载等待。

## 0.3.0.dev13-0.3.0.dev14 2026-10-22

加入 Python 路径选择与检测，以及 MLIP 模型和计算依赖的按需下载安装。配置流程简化为使用现有 Python、勾选模型和 GPU，磁矩显示增加筛选汇总。

## 0.3.0.dev10-0.3.0.dev12 2026-10-21

修复直接导入 OUTCAR，增加磁矩轨道分量选择和原始数据表。支持拖动标签排序，修复多窗口快捷键；测量标记在旋转、播放时保留，小数位可设置。

## 0.3.0.dev9 2026-10-12

渲染支持按元素和单个原子调整外观，改进柔和光照、多面体和显示开关。通用样式与包含结构、视角和单原子设置的完整场景分开保存。

## 0.3.0.dev8 2026-10-11

键长、键角、二面角和面夹角直接在视图中显示数值，并随轨迹播放、跳帧实时更新。

## 0.3.0.dev6-0.3.0.dev7 2026-10-10

新增从 OUTCAR 读取磁矩，Bader 电荷支持按元素筛选。键与原子按相同空间比例缩放；VASP 导出支持分数或笛卡尔坐标，并统一数字排版和周期归位。

## 0.3.0.dev2-0.3.0.dev5 2026-10-07

差分电荷支持正负双色等值面，新增 Bader 电荷和原始数据表。加入最多四格的独立对比页面、目录与文件名双行标签、同步视角，修复多视窗中的文字位置和电子文件切换问题。

## 0.2.0.dev7-0.3.0.dev1 2026-10-05

完成第二个正式版本；计算与播放分离，优化大轨迹、原子序号和曲线悬停性能，增加曲线范围控制、跳帧和图片导出。随后开始第三版，新增 NEB 目录扫描、结构叠加、独立数据筛选、优化曲线及能量路径。

## 0.1.0.dev13-0.2.0.dev6 2026-10-04

形成第一版分享文件和 Windows EXE 启动入口，加入更多模型风格及原子组旋转。随后增加水层、随机水、SMILES 分子、原子过近检测、受力显示、整分子周期归位和多步撤销；接入 NEP89、MACE small-0b2、MH-1，扩展结构、轨迹和电子数据格式，修正切面及 CHGCAR 读取。

## 0.1.0.dev0-0.1.0.dev12 2026-10-03

建立 POSCAR 读写、原子编辑、固定约束、温度、测量、复制粘贴和多结构切换等基础功能。加入轨迹播放、切面扩胞、MACE 优化与预平衡、上下软墙，以及空白结构、Materials Project、石墨烯和碳纳米管构建。
